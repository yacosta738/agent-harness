# Prompt Recipes Reference

Use these recipes as starting points. Always adapt topic-specific content; do not paste placeholders
into final prompts.

## Blog Header Recipe

```text
Create a [LAYOUT PATTERN] style technical infographic for a blog post header about [TOPIC].

AESTHETIC: classified ops terminal × hacker dashboard × technical blueprint.
Pure black background (#000000/#080808), white monospace typography, hairline borders,
dense panels, faint scanlines, restrained semantic status colors only.

COMPOSITION:
- Top command bar: "[TITLE IN CAPS]" + timestamp/subtitle.
- Main panel: [diagram/table/process relevant to topic].
- Secondary panel: [3-5 key points, metrics, or steps].
- Detail strip: [technical labels, commands, tags, hashes, coordinates].
- Bottom corner watermark: small monospace attribution.

TECHNICAL: 16:9, 1920×1080. High contrast.
AVOID: neon, gradients, SaaS cards, rounded corners, stock illustrations, cartoon icons.
```

## LinkedIn Post Recipe

```text
Create a [LAYOUT PATTERN] style technical infographic for a LinkedIn post about [TOPIC].

AESTHETIC: dark terminal-noir visual identity, dense operational dashboard,
monospace labels, sharp panel grid, white/gray on black with dim semantic status accents.

COMPOSITION:
- Strong top headline readable on mobile.
- 2-3 large content zones maximum.
- Center: [main diagram/process/table].
- Side/bottom: [practical takeaway list or status matrix].
- Faint background technical strings related to [TOPIC].

TECHNICAL: 4:5, 1080×1350 unless user requested another LinkedIn format.
AVOID: generic AI neon, corporate SaaS, gradients, decorative icons, too much tiny text.
```

## YouTube Thumbnail Recipe

```text
Create a high-contrast YouTube thumbnail about [TOPIC] in Yuniel's dark ops-terminal style.

AESTHETIC: black command center, bold monospace headline, tactical HUD panels,
white wireframe diagram, one dim status accent if needed.

COMPOSITION:
- Large 3-5 word headline, readable at small size.
- One dominant technical visual: [diagram/object/process].
- Minimal supporting labels: max 3 badges.
- Background: subtle scanlines and technical strings.

TECHNICAL: 16:9, 1280×720. Prioritize readability over detail.
AVOID: clutter, tiny tables, neon glow, reaction-face thumbnail style, bright gradients.
```

## Architecture Poster Recipe

```text
Create an Architecture Poster style technical infographic about [SYSTEM/TOPIC].

COMPOSITION:
- Central isometric wireframe architecture diagram with [LAYERS/SERVICES].
- Arrows showing data/control flow.
- Left panel: component registry table.
- Right panel: runtime/status notes.
- Bottom strip: constraints, protocols, or deployment targets.

STYLE: black background, white wireframe lines, monospace labels, hairline panels,
blueprint depth using line weight and opacity only.
```

## RPG Character Card Recipe

```text
Create an RPG Character Card style personal brand infographic for [PERSON/SUBJECT].

Use navy/teal palette: #0a192f background, #112240/#172a45 cards, #64ffda accents,
#e2e8f0 text, #8892b0 muted text, #233554 borders.

COMPOSITION:
- HUD top bar with PLAYER/LEVEL/XP.
- Left: portrait/avatar, name, role, short bio, mission.
- Right: stat bars with skill scores.
- Achievement row with 3-4 KPIs.
- Bottom panels for skills, experience, categories/stack.

AVOID: terminal monochrome, fantasy UI, corporate SaaS, oversaturated neon.
```
